# Glass Music Visualizer — Android

Экспериментальное Android-приложение в стиле Liquid Glass с 36-полосным FFT-визуализатором, плавающей панелью и кнопками управления Яндекс Музыкой через системную MediaSession.

**Важно:** доступ к аудиопотоку другого приложения может блокироваться Android или самим плеером. Без такого доступа реальные полосы FFT не будут двигаться.

## APK

После публикации исходников workflow **Android APK** собирает `app-debug.apk`. Откройте вкладку [Actions](https://github.com/kosheci/glass-music-visualizer/actions), выберите успешный запуск и скачайте артефакт `GlassMusicVisualizer-APK`. APK для тестирования подписан отладочным ключом GitHub runner.

## Исходники

Android 10+; Kotlin, Gradle. Если в корне находится `source.tar.xz`, исходные файлы также можно получить командой `tar -xJf source.tar.xz`. Workflow распаковывает архив перед сборкой и пытается коммитить извлечённые исходники в репозиторий.

Авторский экспериментальный проект, неофициальный клиент и не продукт Яндекса.
